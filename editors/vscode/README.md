# godot-xaml for VS Code

Language support for [godot-xaml](https://github.com/leftos/godot-xaml)'s `.xscn` scenes and `.xres` resources, the XAML-style files that Godot 4.7+ .NET projects open, edit and save through the godot-xaml addon.

## What it does

- Registers `.xscn` files as the `xscn` language and `.xres` files as the `xres` language.
- Colours both with VS Code's built-in XML grammar, and gives them XML's comments, brackets, auto-closing pairs and folding.

Completion, diagnostics, hover and the rest of the language server's features arrive in a later version of this extension.
