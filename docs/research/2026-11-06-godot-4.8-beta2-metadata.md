# Godot 4.8 beta 2: bundled metadata and hover docs

Date: 2026-11-06

What changed between the bundled Godot 4.7 metadata and the Godot 4.8 beta 2 metadata godot-xaml now carries (GXAML-261). The 4.8 files are regenerated at the release candidate or stable release before a release claims 4.8.

## Source

- Engine: Godot v4.8.beta2.mono.official.cafc17a19.
- `metadata/godot-4.8.json`: `tools/metadata-dump/dump.ps1 -Godot F:/Godot/4.8-beta2/Godot_v4.8-beta2_mono_win64/Godot_v4.8-beta2_mono_win64_console.exe`.
- `metadata/docs/godot-4.8.json`: `tools/class-docs/generate.ps1 -GodotSource F:/Godot/src-4.8-beta2 -Metadata metadata/godot-4.8.json -GodotVersion 4.8.0-beta2 -Out metadata/docs/godot-4.8.json`.

One property removed: `AnimationNodeBlendSpace2D.triangles`. It is gone from the metadata because 4.8 no longer binds it with `ADD_PROPERTY`; the class lists it from `_get_property_list` instead, still stored (`PROPERTY_USAGE_NO_EDITOR | PROPERTY_USAGE_INTERNAL`), so blend points load before it (`scene/animation/animation_blend_space_2d.cpp:477-478`):

```cpp
// This is here and not an ADD_PROPERTY in _bind_methods() because static properties apply before this list, so triangles would serialize before blend points and fail to resolve on deserialization.
p_list->push_back(PropertyInfo(Variant::PACKED_INT32_ARRAY, "triangles", PROPERTY_HINT_NONE, "", PROPERTY_USAGE_NO_EDITOR | PROPERTY_USAGE_INTERNAL));
```

## Stored-property order

Of the classes in both versions, two order their common own properties differently, and `PropertyOrder` follows the metadata, so a file written under 4.8 orders them the 4.8 way.

`DirectionalLight3D` moves `sky_mode` from last to first (`F:\Godot\src-4.8-beta2\scene\3d\light_3d.cpp:612-615`):

```cpp
ADD_PROPERTY(PropertyInfo(Variant::INT, "sky_mode", PROPERTY_HINT_ENUM, "Light and Sky,Light Only,Sky Only"), "set_sky_mode", "get_sky_mode");

ADD_GROUP("Directional Shadow", "directional_shadow_");
ADD_PROPERTY(PropertyInfo(Variant::INT, "directional_shadow_mode", PROPERTY_HINT_ENUM, "Orthogonal (Fast),PSSM 2 Splits (Average),PSSM 4 Splits (Slow)"), "set_shadow_mode", "get_shadow_mode");
```

`SpinBox` moves `prefix` and `suffix` after its new `format`, `plural_format` and `format_auto_translate_mode` (`F:\Godot\src-4.8-beta2\scene\gui\spin_box.cpp:840-848`):

```cpp
ADD_PROPERTY(PropertyInfo(Variant::BOOL, "select_all_on_focus"), "set_select_all_on_focus", "is_select_all_on_focus");

ADD_GROUP("Format", "");
ADD_PROPERTY(PropertyInfo(Variant::STRING, "format", PROPERTY_HINT_PLACEHOLDER_TEXT, "%s"), "set_format", "get_format");
```
