# 5. The coverage test's shape

- Reading a fixture's property names with their class: use the core reader `TscnReader.Read(text)` (SceneRoundTripTests uses it, `RepoFiles.PathOf("tests","fixtures","scenes",file)`), which returns a `TscnDocument` with `Header.Type` (main resource class; `[resource]` section's properties), `SubResources` (each `TscnSubResource.Type` and `.Properties`) and `Nodes` (each `TscnNode.Type`, `.Properties`; `Type` is null for an instance or inherited node, so those need `InstancedClasses` or are skipped).
